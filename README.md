# autismclub-site

The website for Autism Club, an educational centre in Surrey, BC, that runs programs for autistic children and young adults. The site covers the centre's club programs (LEGO, robot coding, music, art, sports and more), its career programs, events, autism funding information and registration.

## Built With

- HTML and CSS
- [Bootstrap](https://getbootstrap.com)
- [jQuery](https://jquery.com)
- [Font Awesome](https://fontawesome.com)

## Running Locally

It's a static site, so there's no build step. Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.
